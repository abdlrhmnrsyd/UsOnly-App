# 💖 Our Space — Frontend Web Application

Frontend interface for **Our Space**, designed for Abdul Rahman Rasyid (Asit) & Anisya (Nisya).

## 🚀 Tech Stack
- **React 19** with JavaScript (ES Modules)
- **Vite 8**
- **Tailwind CSS v4** (`@tailwindcss/postcss`)
- **React Router DOM v7**
- **Lucide React**
- **Leaflet & OpenStreetMap** for interactive maps
- **Zustand** for state management
- **Sonner** for toast notifications
- **Socket.IO Client** for realtime messaging

## 💻 Running the Frontend
From the root directory or inside `client/`:
```powershell
npm run dev
# or
npm --prefix client run dev
```

## 🏗️ Production Build
```powershell
npm run build
# or
npm --prefix client run build
```
Build output is saved to `dist/`.
